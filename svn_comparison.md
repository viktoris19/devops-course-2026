## 1. Почему в Git ветвление «дешёвое», а в SVN — «дорогое»?

В Git ветка — это просто ссылка на коммит. Создать её - значит записать одну строчку, файлы не копируются. Поэтому это мгновенно.

В SVN ветка — это полная копия папки внутри репозитория. Файлы физически дублируются, поэтому создание ветки медленнее и «дороже».

## 2. Можно ли в SVN сделать коммит без интернета? Почему?

Нет, нельзя.

SVN — централизованная система: все версии хранятся только на сервере. Коммит — это запись на сервер, а без интернета до сервера не добраться.

Офлайн в SVN работают только `svn diff` и `svn status` — посмотреть свои изменения. 

В Git наоборот: у каждого своя полная копия репозитория, поэтому коммитить можно офлайн.

## 3. В каких сценариях SVN до сих пор может быть предпочтительнее Git?

1. Нужны права на отдельные папки — в SVN это настраивается точно, в Git сложнее.
2. Простой линейный проект — без ветвления SVN проще для новичков.
3. Нужна только часть репозитория — SVN умеет выгружать отдельные папки.
4. Старый проект, который уже на SVN миграция дороже, чем оставить как есть.
